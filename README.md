# C Library for Practice

This repository is a personal practice project where I am recreating standard C library functions to practice and strengthen my understanding of the C programming language.

## About

The goal of this project is to implement standard utility, string manipulation, and character handling functions from scratch to better understand low-level memory handling, pointers, and algorithms.
